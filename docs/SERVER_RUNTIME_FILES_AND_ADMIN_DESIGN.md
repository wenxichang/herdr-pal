# 服务端运行文件与管理体验设计

## 目标

本次调整统一 Herdr Pal Server 的运行文件位置，允许管理员实时维护企微帮助内容，修正审计日志中的 Agent 信息，并补齐管理员自助改密和外部签发接入说明。

## 文件布局与迁移

服务端默认只使用当前用户 HOME 下的固定目录：

```text
~/.config/herdr-pal-server/
├── server.json
├── auth.json
├── bootstrap.txt
└── help.md
```

- `server.json` 保存服务端配置和企微 Secret。
- `auth.json` 保存管理员密码摘要、自动化 Token 摘要及相关状态。
- `bootstrap.txt` 只在首次创建默认管理员时写入初始用户名、随机密码和自动化 Token。
- `help.md` 保存企微 `/help` 命令返回的完整内容。
- 目录权限为 `0700`，包含凭据的文件权限为 `0600`。
- 不再兼容 `~/.config/herdr-pal/server-config.json`、`server-auth.json` 等旧服务端路径。部署时先备份旧文件，再迁移到新目录。
- Herdr Pal 客户端仍使用 `~/.config/herdr-pal/config.json`，不受本次迁移影响。

首次创建管理员时，服务端以原子方式写入 `bootstrap.txt`，并继续将相同的一次性引导信息打印到标准输出。认证文件已存在时，不重新生成或覆盖该文件。

## 实时帮助内容

服务端收到企微 `/help` 后，每次都重新打开并读取 `help.md`，不在内存中缓存内容。管理员修改文件后，下一次请求立即生效，无需重启服务。

读取行为遵循以下边界：

- 启动时若 `help.md` 不存在，创建包含当前快速上手内容的默认文件。
- 每次读取限制最大尺寸，避免异常文件消耗过多内存。
- 文件不存在、权限不足、内容为空或尺寸超限时，向用户返回明确错误并记录原因，不回退到已缓存内容。
- 帮助内容完全由文件维护，不再动态拼接服务地址。

`addr_hint` 字段及其校验、URL 生成、示例配置和文档全部删除。配置解析保持严格模式，旧配置中出现该字段时明确报错，管理员必须完成迁移后再启动。

## 审计 Agent 信息

审计事件增加独立的 `agent` 字段，记录会话对应的真实 Agent 类型，例如 `claude`、`codex` 或 `opencode`。

- 用户输入和终端文本输出事件都从会话元数据写入 Agent。
- OTLP Logs 增加 `herdr_pal.audit.agent` 属性。
- pane 标识仍可保留为内部诊断字段，但不能代替 Agent。
- Loki 查询结果增加 `agent` 字段，管理页面 AGENT 列只显示该字段。
- 历史日志没有 Agent 属性时显示 `-`，不再回退显示 pane 标识。

## 管理员密码操作

现有当前用户改密接口保持不变，管理页面增加“修改我的密码”表单：

- 要求输入当前密码、新密码和确认密码。
- 修改成功后撤销现有会话并返回登录页，用户使用新密码重新登录。
- 管理员列表中，当前登录用户不显示“重置密码”；其他管理员继续只提供重置操作。
- 其他管理员的密码重置仍生成一次性随机密码，不要求操作者知道对方旧密码。

## 外部签发接入指南

系统页面增加静态的自动化接入指南，说明：

- 自动化签发和删除接口地址。
- Bearer Token 请求头格式。
- 签发凭据和删除凭据的请求、响应及 `curl` 示例。
- Token 只能从管理员页面查看或轮换，指南不嵌入真实 Token。
- 签发返回的机器 Key 只展示一次，调用方必须安全保存。
- 重复签发、来源地址限制和删除后断开连接等行为。

页面使用浏览器当前访问地址生成示例 URL，避免引入新的服务地址配置字段。

## 错误处理与日志

- 配置、认证和帮助文件错误必须包含实际文件路径及具体原因。
- 不在日志中记录企微 Secret、管理员密码、自动化 Token 或机器 Key 原文。
- 帮助文件读取失败记录错误类型和路径，不记录完整帮助内容。
- 审计日志继续记录用户输入和终端文本输出，但图片本身不进入审计内容。

## 测试与验证

新增或更新单元测试，覆盖：

- 服务端四个默认路径和客户端路径互不影响。
- 旧服务端路径停止使用，`addr_hint` 不再参与配置和帮助生成。
- 首次引导文件创建、权限、内容及非覆盖行为。
- `/help` 每次重新读取文件，修改后立即生效，以及缺失、空文件和超限错误。
- 用户输入与终端输出审计事件携带真实 Agent，OTLP 和 Loki 字段映射正确。
- 当前管理员自助改密、其他管理员重置按钮和系统页面接入指南。
- 执行 `./unittest.sh` 和 `./build.sh`，确认全部测试及跨平台构建通过。

## 部署

部署时备份远端旧配置、认证文件、引导文件和服务端二进制，创建新目录并迁移文件，生成默认 `help.md`，再重启服务。重启后验证企微连接、HPRP 客户端重连、Web 管理登录、实时 `/help`、审计查询和外部签发接口。
