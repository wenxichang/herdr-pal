# 特殊命令扩展设计

## 1. 目标

扩展 Herdr Pal 的聊天命令，使选择 Agent、发送 Herdr 斜杠命令和连续 UI 操作更简洁，
同时继续遵守显式按键授权、目标 occupant 校验和按键审计要求。

## 2. 命令协议

### 2.1 Agent 选择简写

`/<NUM>` 等同于 `/sel <NUM>`。`NUM` 必须是正整数，选择范围仍由现有会话注册表校验。

### 2.2 按键命令

保留以下两种形式：

- `/key <KEYS>`
- `/enter`，等同于 `/key enter`

移除 `/keyup`、`/keydn`、`/space` 和 `/esc` 快捷形式；这些字符串作为未知命令处理，
不会降级为普通 prompt。

`KEYS` 可使用逗号或空白分隔，两种分隔符可以混用。连续分隔符和末尾逗号不产生空按键。
每个按键支持：

- 特殊键：`up`、`down`、`enter`、`esc`、`space`
- 缩写：`dn` 展开为 `down`，`sp` 展开为 `space`
- 单个 ASCII 字母或数字，保留原始大小写

解析器先规范化并完整校验整个队列。单独的 `enter` 合法；只要包含 `enter` 且队列长度
大于一，就拒绝整个命令，不能发送任何按键。每条命令最多包含 32 个按键，超出时同样
拒绝整个队列。

### 2.3 帮助命令

`/help` 返回当前支持的全部命令、按键白名单、缩写、分隔规则和 `enter` 限制。

### 2.4 Agent 斜杠命令

`/slash <TEXT>` 去除命令名及其后的分隔空白，在剩余文本前添加 `/`，再作为普通 prompt
发送给当前 Agent。例如 `/slash clear` 发送 `/clear`。

`/slash` 后没有内容时返回用法错误。转换后的 prompt 继续经过现有发送前状态校验、occupant
校验、状态变化确认和 Enter 恢复流程。

## 3. 连续按键执行

按键队列在一次输入操作租约内执行：

1. 完整校验按键队列和当前选中目标。
2. 读取当前 occupant，发现变化时沿用现有会话切换处理。
3. 逐个调用 Herdr `agent.send_keys`，相邻按键发送之间固定等待 100ms，最后一个按键后不等待。
4. 每个实际尝试发送的按键分别写入现有 `KeyAudit`。
5. 全部成功或中途失败后，仅刷新一次最近 100 行控制台内容，行为等同 `/con` 并重置页码。

如果第 N 个按键失败，立即停止后续按键。回复必须说明已成功发送的数量和失败位置；只要至少
一个按键已经成功，仍尝试读取控制台，避免把部分执行误报为完全未发送。控制台读取失败时，
回复应区分“按键已经发送”和“控制台读取失败”。

## 4. 模块修改

- `internal/command`：增加选择简写、按键队列、`/help` 和 `/slash` 解析；集中生成帮助文本。
- `internal/bridge`：顺序执行按键、控制 100ms 间隔、记录逐键审计，并在结束后复用 `/con`
  的读取与分页逻辑。
- `internal/policy`：继续逐键使用现有白名单校验，不扩大允许按键集合。
- `internal/herdr`：继续使用单键 `agent.send_keys` 调用，以保证相邻发送间隔，不引入原始 pane
  输入或私有接口。

## 5. 安全与兼容性

- 所有按键在发送前完成全量校验，非法队列不会部分执行。
- 连续按键仍是用户显式输入，不进行二次确认，也不由状态事件自动触发。
- 每次发送继续携带已选目标并执行 occupant 校验，Agent 被替换时不得将剩余按键发送给新目标。
- 未知 `/` 命令仍返回错误；只有显式 `/slash` 可以把斜杠开头的文本转换为 prompt。
- `/con`、`/pageup` 和 `/pagedn` 继续使用每页 100 行的现有分页语义。

## 6. 测试范围

- `/<NUM>` 与 `/sel <NUM>` 的等价、非法编号和未知斜杠命令。
- 逗号、空白、混合分隔、末尾逗号、缩写和 ASCII 字母数字。
- 单独 `enter`、多键包含 `enter`、超过 32 个按键、非法按键导致整组拒绝。
- 已移除的 `/keyup`、`/keydn`、`/space`、`/esc` 不再可用。
- `/help` 内容以及 `/slash` 的转换和空参数错误。
- 连续按键的顺序、100ms 间隔、中途失败停止、逐键审计和一次控制台刷新。
- 控制台读取失败与按键发送失败的回复能够正确区分。
- occupant 在队列执行期间变化时停止发送剩余按键。
